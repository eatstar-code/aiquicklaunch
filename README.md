# AI QuickLaunch (AI 퀵런치)

클릭 한 번으로 챗GPT, 제미니, 클로드 등 즐겨 찾는 모든 AI 서비스를 동시에 실행하는 최고의 생산성 도구입니다.

매일 똑같은 AI 탭들을 여느라 시간을 낭비하고 계신가요? AI QuickLaunch로 당신의 작업 흐름을 간소화하세요.

## ✨ 핵심 철학: 교차검증과 상호비판을 통한 LLM 답변의 질 향상

AI QuickLaunch는 단순히 탭을 여는 도구가 아닙니다.

이 확장앱의 핵심적인 쓰임새는 여러 LLM을 동시에 사용하여 **답변을 교차 검증(Cross-Validation)**하고, **상호 비판(Mutual Criticism)** 시켜 양질의 결과물을 얻어내는 것입니다.

하나의 AI에 의존하지 않고, 여러 모델의 장단점을 동시에 활용하여 더 깊이 있고 정확한 답을 찾는 파워 유저를 위한 도구입니다.

## 🚀 주요 기능

* **압도적인 시간 절약:** 매번 탭을 하나씩 열 필요 없이, 클릭 한 번으로 모든 AI 작업을 즉시 시작하세요.
* **완벽한 커스터마이징:** 드래그 앤 드롭으로 작업 순서에 맞게 나만의 AI 목록을 자유롭게 편집할 수 있습니다.
* **스마트 토글 관리:** 간단한 ON/OFF 스위치로 이번에 실행할 AI만 정확하게 선택할 수 있습니다.
* **깔끔한 작업 환경:** '탭 고정으로 실행' 옵션을 사용해 브라우저를 깔끔하게 유지하고 AI 탭을 항상 준비된 상태로 만드세요.
* **모든 AI 지원:** 챗GPT, 제미니, 코파일럿, 클로드 등 주요 서비스와 기타 LLM을 지원합니다.
